# 食品工厂HACCP控制计划与偏差处置平台

独立React前端工程，采用Fluent UI、Redux Toolkit、RTK Query、React Router、Vite和TypeScript。数据通过浏览器持久化，无需后端。

## 功能

- 生产批次、放行状态、监测点与隔离范围；投产登记时固定当前控制矩阵版本作为放行依据。
- HACCP流程图和控制矩阵编辑，限值或纠偏措施变更生成新矩阵版本：未签结论的批次按新版本重算，已签批次保留原放行依据并转复核。
- 偏差登记、原因与证据调查、返工/报废分支、复核退回和签字；未关闭偏差与超限/未监测结论阻止批次放行。
- 放行依据一体化：批次详情直接呈现锁定矩阵版本、各控制点限值/实测/判定/纠偏、关联偏差处置与签字信息，追溯包导出为同一份JSON。
- 两窗口（标签页）同时提交时经实体版本校验：后到者保留填写内容并显示冲突，不覆盖已签字数据；跨窗口通过storage事件同步。
- 持久化双写（主文档+备份）：写入失败后从最近完整版本恢复，提交暂存可按幂等键重试，不重复生成审计；审计页可模拟写入故障验证。

端口为`18464`。

```bash
npm install
npm run build
npm run dev
```

## 验证

```bash
npx tsx scripts/verify-release-logic.ts
```

覆盖：投产固定矩阵版本、矩阵变更按签字状态分流、并发提交冲突与签字保护、幂等重试、写入失败恢复、监测补录重算、放行门禁。
